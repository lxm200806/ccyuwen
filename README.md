# 语文培优默写

服务端 FastAPI + PostgreSQL，第一客户端 Vue 3。原始资源分官方目录与用户目录；抽取进草稿库，审核后发布；用户按类型组课程，按 SM-2 默写。

## 启动

本机用 Docker（已有 `postgres:14` 镜像）：

```powershell
docker compose up --build
```

- 客户端：http://localhost:8080/
- API：http://localhost:8000/api/health

账号：`admin` / `admin123`（审核发布），`kid` / `kid123`（学习），`parent` / `parent123`（家长，已绑定 kid）。家长用法见 [docs/parent-account.md](docs/parent-account.md)。

## 资源目录

- 官方：`server/data/official/{年}/{id}_{文件名}`
- 用户：`server/data/users/{userId}/{id}_{文件名}`
- 原文备份：`raw/部编一年级上册.md` 至 `raw/部编六年级下册.md`（共 12 册；运行时再复制到 `server/data/official/bundled/`）
- 小学成语：`raw/idioms/小学成语.json`（课内按年级、分日积月累/课文；其余为教辅常见）。和教材一样在「原始资料」同步后直接进已发布库，不用审核。打印原文：`raw/小学成语.md`
- 知识点：对应的 `raw/部编…册.json`（含 `version`）。改 JSON 或原文后，文件版本会升高；「原始资料」页显示「未同步 / 有更新 / 已同步」。「增量同步」只写入未同步和有更新的材料，「一键重新同步」强制重写十二册和小学成语。按稳定编号 `point_key` 更新已发布条目，不会另插一条

管理员在「原始资料」页上传、备份和同步教材；在「审核」页把 CSV/JSON 抽进草稿并校对发布。学生可浏览已发布知识点（含答案），组课页仍不显示答案。已备份的材料可「增量同步」「一键重新同步」，或单册「同步到知识库」。

导入格式与 `raw/示例导入.csv` 相同：`kind,level,grade,prompt,answer,tags,source`，JSON 还可带 `key`（稳定编号）、可选 `group` / `sub_group`（一二级组 ID）。未填写时，古诗和文言文以 `key` 为组，其余按年级 + 类型 + 模块出处 + 标签主题自动生成一级组 ID。

类型：`poem` 古诗、`wenyan` 文言文、`idiom` 词语、`saying` 俗语名句、`sentence` 优美句子、`zi` 易错字。年级如 `三年级上`。

## 学习

1. 知识点：学生和管理员都能浏览已发布库（题目、答案、出处、能量），可按类型、级别、年级、册筛选，也可按组查看。组课页仍不显示答案。管理员可在此改文案。
2. 组课：勾选年级、类型、级别，并设定每天**新学能量**和**复习能量**（默认各 30）。生成后可在课程页打开「学习计划」，按天查看新学卡和 SM-2 复习卡（按全对估算）。
3. 学习能量：字 1，词语 2，成语 4，古诗按篇幅 16/24/32，文言文 24/32/64/96。同一模块的细卡片组成一张学习卡，能量相加。每天按能量凑满：约 15 的卡可学两张，约 30–35 学一张，50 以上拆成两天。
4. 今日默写：先按复习能量收取到期卡，再按新学能量收取未学卡。对错仍按单条知识点记 SM-2。页面上可选 **学习 / 测试 / 背诵**（先练会、考考你、读出来）；规则见 [docs/study-modes.md](docs/study-modes.md)。
5. 课程掌握：今日已练 / 正确率 / 还差能量，以及学习次数、复习次数、错过次数。掌握页和家长家庭页还能看近 7 日简报、错题再练。
6. 覆盖：全库已组课 / 学过 / 已掌握。
7. 家长：用家长账号看孩子今天和近 7 日情况，勾选到期复习默认测试，用年级向导给孩子组课。默写仍由孩子自己打开。

今日默写做完（队列空或新学+复习能量用完）会显示「今天练完了」。课程可勾选「到期复习默认用测试模式」，也可设今日大约练几分钟。

卡片上限：易错字 1 字，成语一条，古诗短篇或名句（去标点后不超过 80 字），文言文一段（不超过 160 字）。

## 自检

```powershell
docker compose run --rm api python -m unittest tests.test_logic tests.test_api
```

旧的单页 `index.html` 仍可离线打开，逻辑以服务端为准。
