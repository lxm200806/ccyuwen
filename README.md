# 语文培优默写

把教材、试卷里摘出的知识点做成可默写卡片，按 L1–L4 分级，用 SM-2 记忆曲线安排复习。

本机没有强制安装 Python / Node。用浏览器打开即可。

## 怎么用

1. 双击 `index.html`，或在目录里执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

然后打开 http://localhost:8765/

2. **默写**：孩子看提示、写出答案。标点空格不计。全对拉长间隔，错了第二天再来，并在今日队列末尾再练一次。
3. **词库**：按类型/级别浏览，手工加一条。
4. **导入**：从教辅、试卷里整理成 CSV 或 JSON 后粘贴。样例：`raw/示例导入.csv`。
5. **导出**：备份到 `ccyuwen-backup.json`，换电脑再导入。

建议流程：先用内置必背把默写跑起来 → 再把真题名句补进词库。`raw/` 只放自己买的书和试卷的摘录，不要整本传播原版 PDF。

## 级别

| 级别 | 含义 |
|---|---|
| L1 | 课内必背 |
| L2 | 课内拓展 |
| L3 | 小升初/期末高频 |
| L4 | 竞赛超纲 |

类型：`poem` 古诗、`idiom` 成语、`zi` 易错字。

## 自检

浏览器打开 `tests/check.html`，应显示「全部通过」。

## 刻意没做的

OCR 扫教材、大模型自动抽点、账号同步。词库能稳定默写后再加。
