# 部编版二年级上册｜必背古诗 + 日积月累 + 课文优美句子

整理自部编（统编）小学语文教材及公开复习汇编，便于默写备份。改此文件后，在「审核」页同步知识点。

## 一、必背古诗

### 语文园地一

**梅花【宋】王安石**
墙角数枝梅，凌寒独自开。
遥知不是雪，为有暗香来。

### 语文园地三

**小儿垂钓【唐】胡令能**
蓬头稚子学垂纶，侧坐莓苔草映身。
路人借问遥招手，怕得鱼惊不应人。

### 第 8 课 古诗二首

**登鹳雀楼【唐】王之涣**
白日依山尽，黄河入海流。
欲穷千里目，更上一层楼。

**望庐山瀑布【唐】李白**
日照香炉生紫烟，遥看瀑布挂前川。
飞流直下三千尺，疑是银河落九天。

### 语文园地五

**江雪【唐】柳宗元**
千山鸟飞绝，万径人踪灭。
孤舟蓑笠翁，独钓寒江雪。

### 第 18 课 古诗二首

**夜宿山寺【唐】李白**
危楼高百尺，手可摘星辰。
不敢高声语，恐惊天上人。

**敕勒歌　北朝民歌**
敕勒川，阴山下。天似穹庐，笼盖四野。
天苍苍，野茫茫，风吹草低见牛羊。

## 二、全册日积月累（语文园地）

### 语文园地二（待人处世）

己所不欲，勿施于人。——《论语》
与朋友交，言而有信。——《论语》
不以规矩，不能成方圆。——《孟子》

### 语文园地四（写景名句）

有山皆图画，无水不文章。
白马西风塞上，杏花烟雨江南。
清风明月本无价，近水远山皆有情。
雾锁山头山锁雾，天连水尾水连天。

### 语文园地六（立志）

有志者事竟成。——《后汉书》
志当存高远。——诸葛亮
穷且益坚，不坠青云之志。——王勃

### 语文园地七（数九歌）

一九二九不出手。三九四九冰上走。
五九六九，沿河看柳。
七九河开，八九燕来。
九九加一九，耕牛遍地走。

### 语文园地八（含动物的成语）

狼吞虎咽　惊弓之鸟　胆小如鼠
龙飞凤舞　漏网之鱼　如虎添翼
鸡鸣狗吠　害群之马　如鱼得水

### 《树之歌》课后

十年树木，百年树人。
树高百尺，叶落归根。
树无根不长，人无志不立。

## 三、课内优秀短文句子（摘抄、作文可用）

1. 蒲公英妈妈准备了降落伞，把它送给自己的娃娃。只要有风轻轻吹过，孩子们就乘着风纷纷出发。——《植物妈妈有办法》
2. 就说“仙桃石”吧，它好像从天上飞下来的一个大桃子，落在山顶的石盘上。——《黄山奇石》
3. 在一座陡峭的山峰上，有一只“猴子”。它两只胳膊抱着腿，一动不动地蹲在山头，望着翻滚的云海。——《黄山奇石》
4. 日月潭很深，湖水碧绿。小岛把湖水分成两半，北边像圆圆的太阳，叫日潭；南边像弯弯的月亮，叫月潭。——《日月潭》
5. 要是下起蒙蒙细雨，日月潭好像披上轻纱，周围的景物一片朦胧，就像童话中的仙境。——《日月潭》
6. 杨树高，榕树壮，梧桐树叶像手掌。枫树秋天叶儿红，松柏四季披绿装。——《树之歌》
