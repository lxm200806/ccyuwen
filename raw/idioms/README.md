# 小学成语培优全书（1200 条）

面向小学生、教辅与小升初常见考点的成语知识点包。

## 文件

- `小学成语1200.csv`：审核页 CSV 导入
- `小学成语1200.json`：含稳定 `key` / `group`

## 级别分布

| 级别 | 含义 | 数量 |
|---|---|---|
| L1 | 课内必背 | 75 |
| L2 | 课内拓展 / 作文常见 | 217 |
| L3 | 小升初高频 / 教辅常见 | 908 |

## 导入

管理端上传 CSV/JSON → 抽进草稿 → 校对发布。

## 说明

- 词条来自小学教辅高频分类与部编课内成语，释义提示面向默写。
- 开源成语库仅用于补全短提示；已去重为恰好 1200 条。
